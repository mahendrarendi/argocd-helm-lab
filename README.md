# Argo CD Helm Lab

Learn GitOps using Argo CD, Helm, and a sample NGINX application.

## Structure

- bootstrap/: root Argo CD Applications
- charts/applications/: templates for Applications and AppProjects
- charts/gitops-web/: sample web application chart
- values/: environment-specific configuration
- platform/argocd/: Argo CD installation configuration

## Current status

Development configuration is prepared.
Staging and production bootstrap files are placeholders.
